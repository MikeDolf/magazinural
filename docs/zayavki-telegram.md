# Заявки с сайта в Telegram

Форма заявки и «Перезвоните мне» отправляют данные на Cloudflare Worker (`workers/zayavki.js`),
а он пересылает сообщение в ваш Telegram. Бесплатно: лимит Workers — 100 000 запросов в день.
Токен бота вводится только в панели Cloudflare, в чат и в репозиторий его не отправляем.

## 1. Бот (5 минут)

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и адрес бота (например, `magazinural_zayavki_bot`).
2. BotFather пришлёт токен вида `1234567890:AA...`. Сохраните его у себя — он понадобится в шаге 2.
3. Напишите своему боту любое сообщение (иначе бот не сможет вам писать).
4. Узнайте свой id: напишите @userinfobot — он ответит числом `Id: 123456789`.
   Если заявки должны приходить в группу менеджеров: добавьте бота в группу, а id группы
   (начинается с `-100…`) покажет тот же @userinfobot, если переслать ему сообщение из группы.

## 2. Worker (10 минут)

1. Зарегистрируйтесь на dash.cloudflare.com (можно тем же email).
2. **Workers & Pages → Create → Create Worker**. Имя: `zayavki`. Нажмите **Deploy**.
3. **Edit code**: удалите пример, вставьте целиком содержимое `workers/zayavki.js` из репозитория, **Deploy**.
4. **Settings → Variables and Secrets → Add**:
   - тип **Secret**, имя `TG_BOT_TOKEN`, значение — токен от BotFather;
   - тип **Secret**, имя `TG_CHAT_ID`, значение — ваш id из шага 1.4.
   Сохраните (**Deploy**).
5. Скопируйте адрес воркера вида `https://zayavki.<аккаунт>.workers.dev` — это не секрет,
   его можно прислать мне в чат.

## 3. Сайт

В `_build/data/site.py` впишите адрес в `"form_endpoint"`, соберите сайт (`python3 _build/build.py`) и отправьте изменения.
Проверьте: оставьте заявку на сайте — через пару секунд она придёт в Telegram.

## Что защищает от спама

- Worker принимает запросы только со страниц magazinural.ru.
- В формах есть невидимое поле-ловушка: боты его заполняют, такие заявки молча отбрасываются.
- Без телефона (меньше 10 цифр) заявка не принимается.

Если спам всё же пойдёт — подключим Cloudflare Turnstile (бесплатная капча без картинок).
